## 2. Why This Class

**Class 28** covers "games and playthings." A downloadable digital game and the underlying game-rules system both fit. This is the canonical class for board games, card games, and video games sold as games (not as services).

**Class 41 (entertainment services)** is a possible second class for the *online tournament service* once it exists as a hosted service. **Defer Class 41** for the first round — file Class 28 now, add Class 41 later when the online service launches. Filing both classes now doubles the fee with no benefit while you are still pre-launch.

## 5. Specific Considerations Per Mark

### YELLOW JACKET TOUR

- Distinctive: yes (arbitrary in connection with games). Strong mark.
- Risk of refusal on "merely descriptive" grounds: **low**. Yellow jackets are not associated with poker or golf.
- Risk of refusal on "likelihood of confusion" with prior registrations: **must search before filing** (see §7).

### YELLOW JACKET (short form)

- Distinctive: yes (arbitrary in connection with games), same posture as YELLOW JACKET TOUR.
- Risk of refusal on "merely descriptive" grounds: low.
- Risk of likelihood-of-confusion with prior YJ-named marks (sports teams, automotive parts, university mascots): **must search before filing**. The Georgia Tech "Yellow Jackets" registration covers Class 25 (apparel) and Class 41 (sports services); neither is your Class 28 — but check for any third-party Class 28 prior use.
- Filing rationale: short-form mark protects you in casual use, social handles, hashtag use, and conversational reference. Without it, "Yellow Jacket" alone is only protected by common-law and the family-of-marks argument.

### HONEY-STROKE

- Distinctive: yes (suggestive at most). The hyphenated form increases distinctiveness.
- Risk of refusal: low. No known prior use in games.

### SWEET STROKE

- Distinctive: borderline. "Sweet" is a common word; "stroke" is a generic term in golf. The combination is suggestive of the YJT scoring law (the etymological hook: "sweetening the pot" via bets, where honey is a sweetener). The combination is not generic but examiners may push back on the suggestiveness.
- **Mitigation:** narrow the goods/services description to the specific scoring-system context, not the general "card game" or "stroke play" categories. The narrower the goods, the lower the descriptiveness pushback.
- **Filing rationale:** SWEET STROKE protects an alternative consumer-facing brand for the same scoring system. Useful for licensing, second-screen experiences, and casual-product extensions where "Honey-Stroke" feels too in-world. Filing both gives the brand range.
- Risk of likelihood-of-confusion: search TESS for any prior "Sweet Stroke" or "SweetStroke" registration in Class 28 (golf goods, card games) and Class 41 (entertainment services). Adjacent marks like "Sweet Spot" exist in golf-equipment classes — examine carefully.

### BUMBLEBEE

- Distinctive: weak in isolation (a common word). The PTO may push back as "merely descriptive of a bee-themed game" or as a common surname.
- **Mitigation:** narrow the goods/services description to the specific YJT context (a poker variant within a tour-style game). The narrower the goods, the lower the descriptive-refusal risk.
- **Watch:** the famous DreamWorks "Bumblebee" character (Transformers franchise) holds prior rights in some classes. Class 28 with their robot toys exists. Your mark's class overlap creates potential confusion. **Run a USPTO TESS search (§7) and possibly consult counsel before filing this one.**

### BUZZ

- Distinctive: weak. Common word, common name. Many prior registrations exist (Buzz Lightyear, Buzz Aldrin licensing, multiple games).
- **Recommendation:** defer this filing until you have a stylized logo for Buzz the bumblebee character. File the logo as a stylized mark (different filing) — that gives you protection on the specific character design even if the word "Buzz" is too crowded.

## 6. Required Pre-Filing Search (Free, 1 Hour)

Before paying the $250 fee on any mark, run a TESS search to make sure no one else has it. A confused or overlapping prior registration is the #1 reason TEAS applications get rejected.

1. Go to https://tmsearch.uspto.gov.
2. For each mark, run a "Word and/or Design Mark Search (Structured)" with:
   - Term: the mark exactly
   - Search field: "Combined Word Mark"
3. Review results. Look for:
   - Any live registration for the same or similar mark in Class 28 or Class 41.
   - Any pending application for the same.
4. Document findings in a per-mark file: `/IP/trademark-search/MARK_NAME_search_2026-05-02.md`.

If a clear conflict exists, do not file that mark — refile with a modified mark or consult counsel.

## 11. Deferred: 8-Stage Hand-Flow Lexicon (Family-of-Marks Suite)

The eight terms naming the discrete events of a Yellow Jacket Tour hand are documented as proprietary brand terms in `IP_INVENTORY.md` §2.3. They are **not** filed in the first round. The plan for filing them, when commercial launch and stylized assets exist:

### The eight marks (corrected order — see `IP_INVENTORY.md` §2.3)

| # | Mark | Names |
|---|------|-------|
| 1 | **TEA BOX** | Preflop event (deal + opening pot + first betting round combined) |
| 2 | **THE FAIRWAY** | Flop deal (3 community cards revealed) |
| 3 | **THE LAY-UP** | Flop betting event |
| 4 | **THE HAZARD** | Turn deal (4th community card revealed) |
| 5 | **THE APPROACH** | Turn betting event |
| 6 | **THE GREEN** | River deal (5th community card revealed) |
| 7 | **THE PUTT** | River betting event |
| 8 | **THE CUP** | Showdown event |

### Trademark strength assessment per mark

- **TEA BOX**: distinctive (the "Tea/Tee" pun is non-obvious in a card-game context). Strongest of the eight.
- **THE LAY-UP**: hyphenated compound — moderate distinctiveness. Less common in golf than "drive" or "approach." Easier to clear at TESS than the bare-word marks below.
- **THE FAIRWAY, THE HAZARD, THE APPROACH, THE GREEN, THE PUTT, THE CUP**: each is a generic golf word. As **standalone marks** in Class 28 (games), each will face a "merely descriptive of golf concepts" refusal at the examiner level if filed today.

### Why we wait, and why we file as a suite when we do

Filing each as a standalone TEAS application today would likely cost $250 each plus another $250-500 each in office-action responses if the examiner pushes back, and several would still be refused. The protected path is to **file all eight as a "family of marks"** once:

1. The brand is in commerce (so the family is actually demonstrable in use, not just claimed).
2. Stylized treatments exist (logos, in-product visual styling per stage). The stylized form is registrable on its own merits even when the underlying word is descriptive.
3. The product has built consistent association between each term and the YJT system (~6–18 months of consistent use).

Once those conditions are met, file:

- One application per mark in stylized form (8 × $250 = $2,000).
- One umbrella "family of marks" brief filed alongside, arguing that the eight marks share a common element (the YJT hand-flow system) and should be examined as a coordinated suite. This brief is best drafted by counsel; budget $1,000–2,500.

The family-of-marks doctrine (recognized by USPTO and Federal Circuit case law) lets the suite as a whole be distinctive even when individual members are weak, provided the suite has been used together consistently.

### What to do meanwhile

1. **Use all eight terms consistently** in `RULES.md`, `index.html`, marketing copy, social media, and any written communication. Inconsistent use erodes the family-of-marks argument.
2. **Mark each first use in any document with a TM symbol** (`Tea Box™`, `Drive™`, etc.) to declare common-law use. The TM symbol does not require any filing; it is a public assertion of trademark claim.
3. **Save dated examples** of each term being used in a trademark sense. Screenshots of the build, marketing posts, etc. These build the evidentiary record for the eventual family-of-marks filing.
4. **Do not let the terms drift into generic use.** If you describe a competitor's flop bet as "a drive in their game," you have just used Drive generically. Always say "the flop bet" when describing other games. This is the same posture Xerox uses to defend "Xerox" against becoming a generic verb.

## 12. Common Mistakes to Avoid

1. **Filing 1(a) "in-use" without real commerce.** Voids the mark and is grounds for cancellation later. Always 1(b) until truly in commerce.
2. **Custom goods/services wording on TEAS Plus.** Auto-rejection. Use only ID Manual entries.
3. **Filing in the wrong class.** Class 28 (games) is correct; do not file in Class 9 (computer software generally) — that is for non-game software. The games-specific software entry within Class 28 is what you want.
4. **Forgetting the serial number.** Save immediately.
5. **Filing the entity name as owner before the entity exists.** Make sure Blank Canvas, Inc. is actually formed and in good standing in Wyoming before listing it as owner. If the entity doesn't yet exist, file as Dalton Graham individually and re-assign later (§6 of `COPYRIGHT_FILING_BRIEF.md` describes the assignment recordation process; trademark assignments use a similar TEAS form).
6. **Skipping TESS search.** $250 lost when the examiner refuses based on a prior mark you didn't see.
